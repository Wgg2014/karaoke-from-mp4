# MP4 + SRT 卡拉OK任务目录

此目录由 `karaoke-from-mp4` Skill 创建。原始 MP4 和 SRT 位于目录外，程序只读取它们，不会覆盖、删除或修改歌词内容。

- `input/*.srt`：用户提供的已核对字幕副本，文本与原文件一致。
- `output/歌词预览_10秒.mp4`：先检查字体、位置、逐字变色和音画同步。
- `output/最终视频_已烧录字幕.mp4`：可直接发布的 H.264/AAC 成片。
- `output/透明卡拉OK字幕.mov`：带 Alpha 的 ProRes 4444 覆盖轨，无音频。
- `output/处理日志.log`：处理和验证记录。

在剪映中，将原视频放主轨道，将透明 MOV 放上方轨道；两者从 00:00 对齐，不要单独变速字幕轨，最后统一导出。

如需修正歌词，请先修改原 SRT，再把 MP4 和修正后的 SRT 一起拖到 `run.bat`。首次手动运行会在当前目录创建 `.venv` 并安装 `requirements.txt` 中的依赖。
